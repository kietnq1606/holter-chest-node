# Holter Chest Node Firmware

Firmware cho thiết bị đeo Holter ECG (nRF52840 / Zephyr RTOS).

## Ứng dụng thu & đồng bộ dữ liệu BLE (HolterSync)

Sử dụng ứng dụng **HolterSync** để kết nối BLE, đổi tên thiết bị và tải dữ liệu `.bin` về máy tính:

- **Repository:** https://github.com/kietnq1606/holter-ble-sync
